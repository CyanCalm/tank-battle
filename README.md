# 坦克大战 · Battle City

一个用纯 HTML / CSS / JavaScript（Canvas）实现的经典坦克大战（Battle City）网页游戏，无需任何依赖，打开即玩。

## 在线试玩

GitHub Pages：<https://cyancalm.github.io/tank-battle/>

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建或安装任何东西。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| 方向键 / `WASD` | 移动坦克 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `R` | 重新开始 |

触屏设备上会自动显示虚拟摇杆和开火按钮。

## 游戏规则

- 控制己方坦克，消灭所有敌方坦克即可过关。
- **守护基地（鹰徽）**：基地一旦被子弹击中，游戏立即结束。
- 地图中的元素：
  - 🧱 **砖墙**：可被子弹摧毁。
  - ⬛ **钢墙**：普通火力无法摧毁（火力满级后可击穿）。
  - 🌊 **水域**：坦克无法通过，子弹可以飞过。
  - 🌿 **草丛**：会隐藏坦克。
- **道具**：击杀闪烁的"运输车"会掉落道具：
  - ★ 火力升级（最高 3 级）
  - 🛡 护盾（短暂无敌）
  - 💥 手雷（消灭场上所有敌人）
  - ➕ 额外生命
  - ⏱ 时间冻结（敌人短暂停止）

## 特性

- 3 张手绘关卡，通关后循环并逐步提高难度与敌人速度
- 4 种敌人：普通、快速、强化、装甲（需多次命中）
- 分数与最高分本地保存（localStorage）
- 粒子爆炸特效、简易音效（Web Audio）
- 响应式布局，支持桌面键盘与移动端触屏
